# Personal Rules – Nova

This document contains the personal design rules
that guide the development of the system.

These rules help maintain clarity and consistency.

---

## Rule 1 – Everything must belong to a domain

No entity may exist outside:

- Core
- Taxi
- HRM
- Central
- Support
- Config

---

## Rule 2 – User is the universal actor

All actors in the system are users.

Examples:

- Employee
- Taxista
- Admin
- Client
- Hotel

Roles define behaviour.

---

## Rule 3 – Simplicity beats cleverness

If something is difficult to explain,
the design is probably wrong.

---

## Rule 4 – UI must reflect architecture

Every UI section must map to a domain.

---

## Rule 5 – Naming must be consistent

Never mix languages or concepts.
