# NOVA Codex Rules

1. Read all mandatory NOVA documents before editing code.
2. Execute only the current mission from `NEXT.md`.
3. Inspect the existing implementation first.
4. Reuse existing services and components.
5. Preserve behavior unless the mission explicitly changes it.
6. Run relevant tests, builds and boot checks.
7. Report modified files, validations and blockers.
8. Stop after the current mission.
